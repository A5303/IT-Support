Common Windows Issues & Solutions

Slow Performance
 Steps to Diagnose:
1. Open Task Manager (Ctrl+Shift+Esc)
2. Check CPU, Memory, and Disk usage
3. Identify resource-heavy processes
4. Check startup programs

Common Fixes:
- Disable unnecessary startup programs
- Run disk cleanup
- Check for malware
- Add more RAM if consistently high usage

Network Connectivity Issues
Troubleshooting Steps:
1. `ipconfig /all` - Check IP configuration
2. `ping 8.8.8.8` - Test basic connectivity
3. `ping google.com` - Test DNS resolution
4. `netsh winsock reset` - Reset network stack

Password Issues
 Solutions:
- Reset password via Active Directory
- Clear credential manager
- Check account lockout status
